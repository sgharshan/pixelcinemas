# Pixel Cinemas

Pixel Cinemas is a COMP3006 full-stack cinema booking project. It combines a React client, Node.js/Express API, MongoDB persistence and live Socket.IO seat updates.

## Current development commands

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
```

Copy `.env.example` to `.env` before running the complete stack. The project is being developed test-first; the assessment design and implementation plan live in `docs/superpowers/`.
