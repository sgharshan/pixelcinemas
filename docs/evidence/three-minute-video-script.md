# Three-minute demonstration script

**0:00–0:25 — Context.** Introduce Pixel Cinemas, the customer/admin roles and the Vue-inspired but independently branded visual direction.

**0:25–1:20 — Customer journey.** Show the responsive home, catalogue, screening choice, keyboard-operable seat map and approximate view. Open a second private window, hold the same seat in the first and show the live lock in the second. Complete checkout and show the generated ticket/history.

**1:20–1:55 — Administration.** Sign in as the seeded administrator, show statistics, create a film, schedule a screening and explain archive/cancel behaviour.

**1:55–2:35 — Engineering.** Briefly show the component/data/sequence diagrams, REST error shape, hashed credentials, JWT role middleware, server-side pricing, partial unique seat index and Socket.IO expiry/disconnect cleanup.

**2:35–3:00 — Evidence.** Show passing test summaries, GitHub Actions, Docker health, UAT table and one improvement made from real feedback. End with limitations: holds are process-local and payment is deliberately simulated.
